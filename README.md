# PriceMonitorPrinzipWebApi
# Описание
PriceMonitorPrinzipWebApi — это ASP.NET Core Web API сервис, позволяющий отслеживать изменения цен на квартиры с сайта prinzip.su. Пользователи могут подписаться на объявления, а система автоматически проверяет цены в фоновом режиме и отправляет уведомления при их изменении.
# Основные возможности
Подписка на объявления — добавление ссылки на квартиру и email для уведомлений
Фоновая проверка цен — автоматическая сверка цен по расписанию через BackgroundPriceCheckService
Уведомления по email — мгновенная отправка писем при обнаружении изменения цены
История цен — хранение только значимых изменений (без дублирования неизменённых значений)
Простой REST API — интуитивные эндпоинты для управления подписками
Автоматические миграции — SQLite база данных создаётся и обновляется при запуске
